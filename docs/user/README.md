# Welcome to SendStack

> 📝 **Status:** Stub — content will be added as features are implemented.

SendStack is a free WordPress plugin that lets you send your site's emails through a reliable third-party email provider instead of your server's default mail. It supports SMTP, Gmail, SendGrid, and Mailgun — with automatic failover, email logging, and alerts when something goes wrong.
