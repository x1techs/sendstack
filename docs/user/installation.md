# Installation

> 📝 **Status:** Stub — content will be added as features are implemented.

This guide walks you through installing SendStack on your WordPress site.

---

## Requirements

- WordPress 6.2 or higher
- PHP 7.4 or higher
- A supported email provider account (SMTP server, Gmail, SendGrid, or Mailgun)

## Installing from WordPress.org

SendStack is not yet published on WordPress.org. Once it is, you'll be able to install it directly from your WordPress dashboard:

1. Go to **Plugins → Add New**
2. Search for "SendStack"
3. Click **Install Now**, then **Activate**

## Installing Manually

1. Download the latest release `.zip` file from the [GitHub releases page](https://github.com/x1techs/sendstack/releases)
2. In your WordPress admin, go to **Plugins → Add New → Upload Plugin**
3. Choose the downloaded `.zip` file and click **Install Now**
4. Click **Activate**

## After Installation

When you activate SendStack for the first time, the **Setup Wizard** will launch automatically. It will walk you through choosing an email provider and entering your credentials. You can also skip the wizard and configure everything manually from **Settings → SendStack**.

## Updating

Once SendStack is listed on WordPress.org, updates will appear automatically in your **Dashboard → Updates** screen, just like any other plugin. Click **Update Now** to apply.

If you installed manually from GitHub, download the latest release and repeat the manual installation steps above — WordPress will replace the old version.
