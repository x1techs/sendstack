## Is SendStack really free?

Yes — SendStack is 100% free and open source (GPL v2+). There is no "Pro" version, no premium add-ons, and no feature gating. Every feature listed on our GitHub page is included at no cost.

## Do I need technical knowledge to set it up?

No. The Setup Wizard guides you through everything step by step. If you can copy and paste an API key, you can configure SendStack. Each provider setup page includes clear instructions.

## Will SendStack work with WooCommerce?

*Answer coming soon.* Short answer: yes — SendStack replaces WordPress's `wp_mail()` function, so any plugin that sends email through WordPress (including WooCommerce, Contact Form 7, and others) will automatically use your configured provider.
